# E03.01 Exact pins, 7-day cooldown, lockfile

**Epic:** E03 · Workspace, seams, and guardrails · **Milestone:** 1 Foundation · **Step:** 1  
**Epic issue:** [#46](https://github.com/midnightntwrk/midnight-passport-sdk/issues/46)  
**Packages:** repo  
**Readiness:** ready · **Sheet title:** Toolchain pins

## Description

Pin every dependency to an exact version, at least 7 days old, with a committed lockfile.

Versions are checked with npm view, never from memory, and there is no custom registry config. A younger version needs a recorded security exception.

## Dependencies

**Blocked by:** nothing.  
**Unlocks:** E03.07 Signed npm release pipeline

## Acceptance criteria

- Every dependency is pinned exactly, with a committed lockfile.
- CI rejects a version younger than 7 days without a recorded security exception.
