# E04.12 Existing-account lookup by passkey

**Epic:** E04 · Account deployment · **Milestone:** 1 Foundation · **Step:** 7  
**Epic issue:** [#47](https://github.com/midnightntwrk/midnight-passport-sdk/issues/47)  
**Packages:** owner  
**Readiness:** ready · **Sheet title:** Recognize the account

## Description

When the user comes back on the same device, the SDK finds their existing account instead of creating a new one.

The account address is found from the passkey and local state, and checked on chain through the indexer seam. Done when a returning user never deploys a second account.

## Dependencies

**Blocked by:** E04.06 Indexer seam: tx status and ACC state; E04.07 WebAuthn create with PRF → JubJub device key  
**Unlocks:** E06.03 Returning-user account resume

## Acceptance criteria

- A returning user on the same device is matched to their existing account.
- The match is confirmed on chain through the indexer.
