# E22.02 Read-grant viewing-key lifecycle (rule 13)

**Epic:** E22 · Read-access lifecycle · **Milestone:** 7 Account recovery · **Step:** 13  
**Epic issue:** [#60](https://github.com/midnightntwrk/midnight-passport-sdk/issues/60)  
**Packages:** owner  
**Readiness:** ready · **Sheet title:** Read-grant lifecycle

## Description

For grants that can read private data: rotate keys before sharing, and re-seal data after a change.

Rule 13: rotate the viewing key before sharing it, re-seal or mark after each rotation, and rotate on revocation. The viewing key leaves whole only to a read-grant holder, after a separate consent.
