# E10.01 Shared scope type for all grantees

**Epic:** E10 · Scoped grants ceremony · **Milestone:** 3 Control · **Step:** 6  
**Epic issue:** [#53](https://github.com/midnightntwrk/midnight-passport-sdk/issues/53)  
**Packages:** protocol, core  
**Readiness:** ready · **Sheet title:** One permission model

## Description

The same rules (operations, assets, limits, expiry) apply to devices and apps alike.

Devices, dApps, and agents share one scope type: operations, assets, limits, and expiry. Defined with the scoped-grants MIP.
