# E04.05 adapter-browser and adapter-nodejs

**Epic:** E04 · Account deployment · **Milestone:** 1 Foundation · **Step:** 5  
**Epic issue:** [#47](https://github.com/midnightntwrk/midnight-passport-sdk/issues/47)  
**Packages:** adapter-browser, adapter-nodejs  
**Readiness:** ready · **Sheet title:** Platform adapters

## Description

The same SDK code runs in the browser (passkeys, WASM loading) and in Node.js.

adapter-browser loads the two WASM runtimes in the correct order and wraps passkeys with PRF. adapter-nodejs gives backends and agents the same seams.
