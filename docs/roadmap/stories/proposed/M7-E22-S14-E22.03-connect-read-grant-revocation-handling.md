# E22.03 connect: read-grant revocation handling

**Epic:** E22 · Read-access lifecycle · **Milestone:** 7 Account recovery · **Step:** 14  
**Epic issue:** [#60](https://github.com/midnightntwrk/midnight-passport-sdk/issues/60)  
**Packages:** connect, owner  
**Readiness:** ready · **Sheet title:** Revoke data access

## Description

The user can withdraw a dApp's access to their private data at any time.

Revoking the read grant triggers the viewing-key rotation of rule 13. The dApp loses access on its next read.

## Dependencies

**Blocked by:** E10.05 Grant revocation call; E18.01 connect: package-key handoff; E22.01 Viewing-key rotation on revocation  
**Unlocks:** no other story.

## Acceptance criteria

- After a read-grant revocation, the dApp loses access on its next read and handles it cleanly.
