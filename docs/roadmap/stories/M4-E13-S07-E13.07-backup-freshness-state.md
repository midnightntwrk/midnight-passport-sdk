# E13.07 Backup freshness state

**Epic:** E13 · Private data and backup · **Milestone:** 4 Private data and sync · **Step:** 7  
**Epic issue:** [#56](https://github.com/midnightntwrk/midnight-passport-sdk/issues/56)  
**Packages:** owner  
**Readiness:** ready · **Sheet title:** Backup states

## Description

Show the user whether the backup is current, stale, or missing.

Current means the backup includes the latest viewing-key rotation. Stale backups are flagged after each rotation.

**Blocked by:** E13.03 Password-wrapped WPP backup  
**Unlocks:** E15.01 Backup and restore screens

## Acceptance criteria

- The backup state shows current, stale, or missing; it goes stale after each viewing-key rotation.
