# E03.09 Secret redaction and zeroization

**Epic:** E03 · Workspace, seams, and guardrails · **Milestone:** 1 Foundation · **Step:** 5  
**Epic issue:** [#46](https://github.com/midnightntwrk/midnight-passport-sdk/issues/46)  
**Packages:** owner, core  
**Readiness:** ready · **Sheet title:** Secret hygiene

## Description

Secrets never appear in logs or error messages, and secret memory is zeroed after use.

Typed errors carry no key material. Buffers that held a PRF output or a key are zeroed after the one operation that needs them.
