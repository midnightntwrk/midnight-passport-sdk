# E03.04 Owner kernel secret boundary

**Epic:** E03 · Workspace, seams, and guardrails · **Milestone:** 1 Foundation · **Step:** 4  
**Epic issue:** [#46](https://github.com/midnightntwrk/midnight-passport-sdk/issues/46)  
**Packages:** owner  
**Readiness:** ready · **Sheet title:** Kernel boundary

## Description

Keep all secrets (owner keys, viewing keys) inside a small kernel; the rest of the SDK never handles them directly.

The owner kernel is the only place that holds the PRF output, the device key, the WPP account key, the viewing key, and the recovery secret in plaintext. Everything else gets signatures or ciphertext.

## Dependencies

**Blocked by:** E03.02 Monorepo scaffold for mn-passport-* packages  
**Unlocks:** E03.09 Secret redaction and zeroization; E04.08 WebAuthn create with PRF → JubJub device key; E17.01 WPP client and storage seam

## Acceptance criteria

- Only the kernel module in `owner` can hold the PRF output, device key, WPP account key, viewing key, and recovery secret.
- A lint or test fails when another module imports kernel internals.
