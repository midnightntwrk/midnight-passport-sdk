# E19.04 Viewing-key distribution to each device

**Epic:** E19 · Devices and multi-device sync · **Milestone:** 6 Private data and sync · **Step:** 9  
**Epic issue:** [#57](https://github.com/midnightntwrk/midnight-passport-sdk/issues/57)  
**Packages:** owner  
**Readiness:** ready · **Sheet title:** Viewing key on every device

## Description

Each device securely receives the viewing key, so it can read the account's private data.

The viewing key is sealed to each device's key and delivered once. Any rotation re-seals it for every device on the account.

**Blocked by:** E17.02 Password-wrapped WPP backup; E19.02 Owner key add and remove on the ACC
