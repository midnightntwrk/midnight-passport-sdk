# E21.01 Intent joiner: dApp intent + ACC payment

**Epic:** E21 · Execution under a grant key · **Milestone:** 7 Execution · **Step:** 5

## Description

Combine a dApp's action and the account's payment into one transaction, so they settle together.

The joiner is a helper the caller can use: it joins the dApp's intent and the account's payment so they settle in one transaction.

## Dependencies

**Blocked by:** E05.03 ACC artifact loader (module, decoder, manifest)  
**Unlocks:** E21.05 connect: Pay with Passport (deposit + joiner); E24.04 Cross-chain swap or spend via joiner

## Acceptance criteria

- The joiner combines a dApp intent and an ACC payment so they settle in one transaction; neither is submitted alone.
