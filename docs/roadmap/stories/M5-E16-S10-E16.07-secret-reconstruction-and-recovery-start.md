# E16.07 Secret reconstruction and recovery start

**Epic:** E16 · Guardian recovery · **Milestone:** 5 Account recovery · **Step:** 10  
**Epic issue:** [#59](https://github.com/midnightntwrk/midnight-passport-sdk/issues/59)  
**Packages:** owner  
**Readiness:** ready · **Sheet title:** Recover

## Description

Restore the same Passport on a new device once enough guardians approve.

With enough shares, the new device rebuilds the recovery secret in its kernel and starts the on-chain recovery. The account address stays the same.
