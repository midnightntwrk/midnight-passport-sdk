# E10.05 Grant revocation call

**Epic:** E10 · Scoped grants ceremony · **Milestone:** 3 Control · **Step:** 9  
**Epic issue:** [#53](https://github.com/midnightntwrk/midnight-passport-sdk/issues/53)  
**Packages:** owner  
**Readiness:** ready · **Sheet title:** Revoke

## Description

Turn off any grant in one tap; the revocation is visible on-chain.

Revocation is a call on the account, signed with an owner key. The dApp or agent sees it on its next grant read.

## Dependencies

**Blocked by:** E10.03 issue_grant call  
**Unlocks:** E12.04 Grant list and revoke screen; E22.01 Viewing-key rotation on revocation; E22.03 connect: read-grant revocation handling

## Acceptance criteria
