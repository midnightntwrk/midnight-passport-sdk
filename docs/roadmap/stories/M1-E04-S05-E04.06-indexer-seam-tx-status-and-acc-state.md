# E04.06 Indexer seam: tx status and ACC state

**Epic:** E04 · Account deployment · **Milestone:** 1 Foundation · **Step:** 5  
**Epic issue:** [#47](https://github.com/midnightntwrk/midnight-passport-sdk/issues/47)  
**Packages:** core  
**Readiness:** ready · **Sheet title:** Status via the indexer

## Description

Read transaction status and account changes through an indexer seam, so no single hosted indexer is required.

The indexer sees only what the viewing key opens. Done when a deploy or a call can be followed to its final state without a vendor-specific API.
