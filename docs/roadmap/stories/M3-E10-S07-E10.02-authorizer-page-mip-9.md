# E10.02 Authorizer page (MIP §9)

**Epic:** E10 · Scoped grants ceremony · **Milestone:** 3 Control · **Step:** 7

## Description

The Passport app page where the user sees exactly what a dApp or agent is asking for, and approves or declines.

The authorizer page of MIP §9. It shows the dApp or agent, the scope in plain language, and the expiry, then takes one passkey tap (rule 1).

## Dependencies

**Blocked by:** E09.01 GrantRequest: browser profile; E10.01 Shared scope type for all grantees  
**Unlocks:** E10.03 issue_grant call; E11.03 connect: browser grant ceremony; E12.01 Authorizer screens (browser and agent profiles)

## Acceptance criteria

- The authorizer page validates a request for both profiles and shows exactly what is asked.
- Approval takes one passkey tap (rule 1).
