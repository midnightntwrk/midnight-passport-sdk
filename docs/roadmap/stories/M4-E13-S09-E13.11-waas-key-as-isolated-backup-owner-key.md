# E13.11 WaaS key as isolated backup owner key

**Epic:** E13 · Private data and backup · **Milestone:** 4 Private data and sync · **Step:** 9

**Packages:** owner, adapter-waas  
**Readiness:** ready · **Sheet title:** WaaS backup owner key

## Description

An optional backup owner key held by a wallet-as-a-service provider, only when the provider isolates it to the Passport app.

Rule 12: the WaaS key is only an isolated backup owner key, with protected, authenticated, and current metadata. It is never the main key and never used from a dApp.
