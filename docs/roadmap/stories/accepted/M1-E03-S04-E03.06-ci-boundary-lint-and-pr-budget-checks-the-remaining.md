## Description

The boundary lint, the dependency-rules tests and the diff-size job are already wired into CI. They have never run against real package code, and the size job only warns. This story closes those gaps once the packages exist.

In scope: Run `scripts/lint-boundaries.mjs` against the real `src` of every package. A fixture that proves rule 4 (connect and agent never link owner): an import of `owner` from `connect` or `agent`, direct or through another package, fails CI. The PR size job reports the count against 400 and 600 lines, fails above 600, and documents how to record an exception. State what the size job counts: today it is insertions plus deletions, lockfile included.

Out of scope: the Effect and `.d.ts` guards, which come with E03.10 (Effect 4 inside the SDK). The two-copy check, which is in E03.01 (stack pins).

## Dependencies

**Blocked by:** E03.02 Monorepo scaffold for mn-passport-* packages  
**Unlocks:** nothing on the board. It protects every later story.

## Acceptance criteria

- CI runs the boundary lint over all scaffolded packages and passes.
- The fixture with a direct `owner` import from `connect` fails; so does the fixture with a transitive one.
- A fixture adapter that imports a package outside its allowed list fails.
- A PR above 600 counted lines fails the size job unless the PR body carries the documented exception line.
- The lockfile and generated files are excluded from the count, or the doc says they are not.
