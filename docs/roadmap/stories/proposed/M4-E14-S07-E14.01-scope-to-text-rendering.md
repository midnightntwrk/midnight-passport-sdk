# E14.01 Scope-to-text rendering

## Description

The user sees, in plain language, what the agent will be allowed to do.

Renders the shared scope type from E10 as sentences on the approval page, such as "may spend up to 50 NIGHT until Friday".

**Blocked by:** E10.01 Shared scope type for all grantees  
**Unlocks:** no other story.

## Acceptance criteria

- The shared scope type renders as plain sentences on the approval page and in agent logs.
