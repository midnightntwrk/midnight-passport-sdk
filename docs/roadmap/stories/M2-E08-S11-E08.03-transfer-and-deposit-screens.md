## Description

Pay someone by name or address, and see incoming payments.

Sends to a name or a full shielded address. Shows a deposit flow for receiving, never the raw account address (rule 3).

## Dependencies

**Blocked by:** E07.02 Transfers via deposit calls  
**Unlocks:** no other story.

## Acceptance criteria

- A user sends to a name or an address, and receives through a deposit flow.
- No screen shows a raw ACC address as a payment address.
