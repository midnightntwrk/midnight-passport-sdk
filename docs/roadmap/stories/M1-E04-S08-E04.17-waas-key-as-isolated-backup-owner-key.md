# E04.17 WaaS key as isolated backup owner key

**Epic:** E04 · Account deployment · **Milestone:** 1 Foundation · **Step:** 8  
**Epic issue:** [#47](https://github.com/midnightntwrk/midnight-passport-sdk/issues/47)  
**Packages:** owner, adapter-waas  
**Readiness:** ready · **Sheet title:** WaaS backup owner key

## Description

An optional backup owner key held by a wallet-as-a-service provider, only when the provider isolates it to the Passport app.

Rule 12: the WaaS key is only an isolated backup owner key, with protected, authenticated, and current metadata. It is enrolled at deploy as a second owner key on the k256 arm, never the main key and never used from a dApp.

## Dependencies

**Blocked by:** E04.07 adapter-waas: k256 key and account metadata; E04.14 WebAuthn PRF support matrix and fallbacks  
**Unlocks:** E04.19 Recovery via the WaaS backup owner key

## Acceptance criteria

- The WaaS key is enrolled at deploy as a second owner key on the k256 arm, only with a provider that isolates it (rule 12).
- Its metadata is protected and current.
