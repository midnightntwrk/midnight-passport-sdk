## Description

After the user approves the agent and gives the separate private-state consent, Passport returns the dApp's package key sealed to the agent.

ADR 0008. The agent request carries an encryption public key bound by its self-signature, and Passport seals the package key to it. The key arrives with the readable scope and its salt, on the agent profile's existing channel. This bumps PROTOCOL_VERSION.
