# E05.04 Binding version registry

**Epic:** E05 · Contract binding · **Milestone:** 1 Foundation · **Step:** 5  
**Epic issue:** [#48](https://github.com/midnightntwrk/midnight-passport-sdk/issues/48)  
**Packages:** contract  
**Readiness:** ready · **Sheet title:** Version registry

## Description

Map each deployed contract version to the binding that can talk to it, and refuse unknown versions.

This is the binding version axis (rule 5). A deployed ACC with an unknown version gets a typed error, never a best-effort call.

## Dependencies

**Blocked by:** E03.05 Wire and binding version axes; E05.03 ACC artifact loader (module, decoder, manifest)  
**Unlocks:** no other story.

## Acceptance criteria

- Each deployed ACC version maps to its binding.
- An unknown version gets a typed error.
