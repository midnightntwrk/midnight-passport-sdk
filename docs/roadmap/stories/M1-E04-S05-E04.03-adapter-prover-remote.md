**Readiness:** ready · **Sheet title:** Remote prover

## Description

The SDK sends an unproven transaction to the proving service and gets the proven transaction back, so clients never handle proving keys.

Implemented by adapter-prover-remote: transaction in, proof out. The prover holds the proving keys or makes them again from the ZKIR and the on-chain verifier key.
