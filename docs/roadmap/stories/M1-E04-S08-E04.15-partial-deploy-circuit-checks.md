# E04.15 Partial-deploy circuit checks

**Epic:** E04 · Account deployment · **Milestone:** 1 Foundation · **Step:** 8  
**Epic issue:** [#47](https://github.com/midnightntwrk/midnight-passport-sdk/issues/47)  
**Packages:** owner, core  
**Readiness:** ready · **Sheet title:** Partly deployed account

## Description

The SDK works with an account whose waves aren't all deployed yet, and only requires the circuits a given call needs.

Each call checks that the circuits it needs are deployed, and returns a typed error if not. A user can start using the account before the last wave lands.

## Dependencies

**Blocked by:** E04.12 Multi-wave ACC deploy planner  
**Unlocks:** no other story.

## Acceptance criteria

- A call that needs an undeployed circuit gets a typed error.
- Calls that only need deployed circuits work while later waves are pending.
