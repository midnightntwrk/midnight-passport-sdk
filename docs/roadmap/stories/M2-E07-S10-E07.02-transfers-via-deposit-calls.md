# E07.02 Transfers via deposit calls

**Epic:** E07 · Payments · **Milestone:** 2 Account management and core actions · **Step:** 10  
**Epic issue:** [#50](https://github.com/midnightntwrk/midnight-passport-sdk/issues/50)  
**Packages:** core, owner  
**Readiness:** ready · **Sheet title:** Send and receive

## Description

Send NIGHT or private tokens to a name or address, with fees covered, and receive payments.

A payment uses the full shielded address, both halves parsed from one address (rule 6). After SucceedEntirely, the SDK writes the result back (rule 8).

## Dependencies

**Blocked by:** E04.16 Name-to-ACC resolution; E07.01 Coin store and encrypted inbox  
**Unlocks:** E08.03 Transfer and deposit screens; E21.05 connect: Pay with Passport (deposit + joiner)

## Acceptance criteria

- The owner pays a name or a full shielded address, both halves parsed from one address (rule 6).
- Paying a Passport is a deposit call (rule 3).
- Write-back happens only after SucceedEntirely (rule 8).
