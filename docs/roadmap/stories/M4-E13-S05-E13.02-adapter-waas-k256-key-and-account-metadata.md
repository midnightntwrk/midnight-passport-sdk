# E13.02 adapter-waas: k256 key and account metadata

**Epic:** E13 · Private data and backup · **Milestone:** 4 Private data and sync · **Step:** 5  
**Epic issue:** [#56](https://github.com/midnightntwrk/midnight-passport-sdk/issues/56)  
**Packages:** adapter-waas, core  
**Readiness:** ready · **Sheet title:** WaaS adapter and metadata

## Description

The adapter for the WaaS provider, plus the public account metadata it stores (never the viewing key).

adapter-waas holds the k256 envelope 0 key and its metadata: namespaced, versioned entries, each written by a read, merge, write, and read back. Entries stay small, because some providers keep only 2 KB.
