# E22.01 Viewing-key rotation on revocation

**Epic:** E22 · Read-access lifecycle · **Milestone:** 7 Account recovery · **Step:** 13  
**Epic issue:** [#60](https://github.com/midnightntwrk/midnight-passport-sdk/issues/60)  
**Packages:** owner  
**Readiness:** ready · **Sheet title:** Rotate after revocation

## Description

Rotate any keys a revoked grant could still use, so access really ends.

If the grant could read private data, the viewing key is rotated after revocation (rule 13), so old access really ends.

## Dependencies

**Blocked by:** E10.05 Grant revocation call; E19.04 Viewing-key distribution to each device; E21.11 Recovery wrap renewal and state restore  
**Unlocks:** E22.03 connect: read-grant revocation handling

## Acceptance criteria

- Revoking a grant that could read private data rotates the viewing key, re-sealed for every device and the recovery wrap.
