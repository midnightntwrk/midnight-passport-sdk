# E14.01 Device enrollment request (QR or link payload)

**Epic:** E14 · Devices and multi-device sync · **Milestone:** 4 Private data and sync · **Step:** 5  
**Epic issue:** [#57](https://github.com/midnightntwrk/midnight-passport-sdk/issues/57)  
**Packages:** protocol, owner  
**Readiness:** ready · **Sheet title:** Out-of-band request

## Description

The message a new device shows (for example as a QR code) so an existing device can approve it.

The new device shows a signed request with its public key, as a QR code or a link. An existing device scans it and approves the add with a tap.

## Dependencies

**Blocked by:** E03.08 Domain-separation tag constants  
**Unlocks:** E14.02 Owner key add and remove on the ACC; E14.05 New-device bootstrap: keys and state

## Acceptance criteria

- A new device shows a signed request with its key, the target account, and a short expiry.
- Replayed or expired requests are rejected.
