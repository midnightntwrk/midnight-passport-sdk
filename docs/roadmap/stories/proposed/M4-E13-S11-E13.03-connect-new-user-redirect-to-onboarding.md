# E13.03 connect: new-user redirect to onboarding

**Epic:** E13 · Connect for dApps · **Milestone:** 4 Integrations · **Step:** 11

**Packages:** connect, owner  
**Readiness:** ready · **Sheet title:** Continue with Passport

## Description

A new user is sent to the Passport app to create an account, then returns to the dApp.

Rule 11: a dApp never onboards a user. It sends a new user to the Passport app, which onboards them and issues the dApp's grant in the same visit.
