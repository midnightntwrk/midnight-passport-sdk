# E20.02 Devices screen (owner key list)

**Epic:** E20 · Passport app: Backup and devices · **Milestone:** 6 Private data and sync · **Step:** 9

**Readiness:** ready · **Sheet title:** Devices screen

## Description

See all devices on the account, add a new one, and remove or switch off a lost one.

Lists each device's owner key, when it was added, and its arm. Removing a device needs a passkey tap on another device.
