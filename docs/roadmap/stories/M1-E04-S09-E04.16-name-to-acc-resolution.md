# E04.16 Name-to-ACC resolution

**Epic:** E04 · Account deployment · **Milestone:** 1 Foundation · **Step:** 9  
**Epic issue:** [#47](https://github.com/midnightntwrk/midnight-passport-sdk/issues/47)  
**Packages:** core  
**Readiness:** ready · **Sheet title:** Name resolution

## Description

Turn a name into the account it belongs to, so people can pay a name instead of an address.

Resolution returns the account, and payment then goes through a deposit call (rule 3). The raw ACC address is never shown as a payment address.

## Dependencies

**Blocked by:** E04.15 Name registration call  
**Unlocks:** E06.04 Name claim step after deploy; E07.02 Transfers via deposit calls; E19.02 connect: sign-in verification

## Acceptance criteria

- `core` resolves a name to its ACC.
- An unknown name returns a typed result, not an exception.
