# E21.03 Grant-key call pipeline: sign, prove, broadcast

**Epic:** E21 · Execution under a grant key · **Milestone:** 7 Execution · **Step:** 10  
**Epic issue:** [#64](https://github.com/midnightntwrk/midnight-passport-sdk/issues/64)  
**Packages:** core  
**Readiness:** ready · **Sheet title:** Calls under a grant key

## Description

Build a call, sign it with the grant key, prove it, and submit it.

Builds the ACC challenge for the grant key's arm, signs it, sends the unproven transaction to the prover, and broadcasts through the sponsor. The Passport app is not on the path (rule 9).

## Dependencies

**Blocked by:** E04.02 KeyProvider across k256, p256, and JubJub; E04.03 adapter-prover-remote; E04.04 adapter-broadcast: submit, finality, resubmit; E10.04 On-chain grant reads and scope helpers  
**Unlocks:** E21.04 connect: grant-key calls, Passport closed; E21.06 agent: grant-key calls on Node.js

## Acceptance criteria

- A call under a grant key builds the challenge for the key's arm, signs, proves, and broadcasts, without the owner key.
