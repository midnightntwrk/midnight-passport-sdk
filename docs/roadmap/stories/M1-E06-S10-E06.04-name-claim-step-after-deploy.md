# E06.04 Name claim step after deploy

**Epic:** E06 · Passport app: Onboarding · **Milestone:** 1 Foundation · **Step:** 10

**Packages:** app  
**Readiness:** ready · **Sheet title:** Claim a name

## Description

Right after the account is deployed, the user picks a name like maya.night, so their Passport has a name from the first visit.

Built on owner and the E07 name claim. The app checks availability while the deploy waves land, then claims the name with the owner key once the account is live. A user can skip it and claim a name later from the account screens.
