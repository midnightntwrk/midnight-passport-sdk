# E04.07 WebAuthn create with PRF → JubJub device key

**Epic:** E04 · Account deployment · **Milestone:** 1 Foundation · **Step:** 6  
**Epic issue:** [#47](https://github.com/midnightntwrk/midnight-passport-sdk/issues/47)  
**Packages:** owner, adapter-browser  
**Readiness:** ready · **Sheet title:** Create with a passkey

## Description

The user creates a passkey (face or fingerprint) on the device, and it becomes the account's first owner key.

WebAuthn with the PRF extension gives a per-device secret, and the kernel derives a JubJub device key from it. On the p256 arm, the key stays in the authenticator.

## Dependencies

**Blocked by:** E03.04 Owner kernel secret boundary; E04.02 KeyProvider across k256, p256, and JubJub  
**Unlocks:** E04.11 Multi-wave ACC deploy planner; E04.12 Existing-account lookup by passkey; E04.13 WebAuthn PRF support matrix and fallbacks; E06.01 Onboarding flow: passkey creation

## Acceptance criteria

- A passkey with PRF is created, and the kernel derives a JubJub device key from it.
- The PRF output and the key are discarded after the operation.
