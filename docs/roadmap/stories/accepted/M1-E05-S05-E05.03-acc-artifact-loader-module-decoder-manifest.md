# E05.03 ACC artifact loader (module, decoder, manifest)

**Epic:** E05 · Contract binding · **Milestone:** 1 Foundation · **Step:** 5  
**Epic issue:** [#48](https://github.com/midnightntwrk/midnight-passport-sdk/issues/48)  
**Packages:** contract  
**Readiness:** ready · **Sheet title:** Load the contract artifact

## Description

`contract` loads the published account contract (ACC) artifact, checks every file against the manifest, and gives the rest of the SDK typed access: the compiled module, the ledger state decoder, the verifier keys, the pure circuits and the circuit lists per arm. The SDK never compiles the contract.

In scope: The manifest schema: file hashes, compiler version, zkir version, binding version, circuits per arm, the wave-1 list per arm, the WebAuthn origin length. The loader: read, verify hashes, refuse on any mismatch with a typed error. A typed ledger decoder: devices, grants, `auth_nonce`, recovery state. Access to the contract's pure circuits, for the digest test vectors of E04.02 (key providers). Lazy loading: verifier keys and ZKIR only when a caller asks; never a proving key. The pinned manifest hash committed in the repo, with one command to update it. All midnight-js and compact-js calls go through the adapter file of E03.10 (Effect 4 inside the SDK).

Out of scope: binding to a deployed account, which is E04.15 (partial-deploy binding). Mapping deployed accounts to versions, which is E05.04 (binding version registry). dApp artifacts.

## Acceptance criteria

- The pinned artifact loads in Node.js and in headless Chromium.
- An artifact with one byte changed in any file is refused, and the error names the file.
- An artifact whose manifest hash differs from the committed pin is refused.
- The decoder reads the state of a real account from a local node, and each field has a type (no `any`).
- Loading the module does not fetch verifier keys, ZKIR or proving keys (test with a network recorder).
- The compiler and runtime versions in the manifest are checked against the pin table of E03.01 (stack pins).
