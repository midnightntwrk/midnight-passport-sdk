# E05.02 ACC circuit interface for dApp composition

**Epic:** E05 · Contract binding · **Milestone:** 1 Foundation · **Step:** 2  
**Epic issue:** [#48](https://github.com/midnightntwrk/midnight-passport-sdk/issues/48)  
**Packages:** contract  
**Readiness:** ready · **Sheet title:** Contract interface for dApp circuits

## Description

Publish the account contract's interface so dApp contracts can call it from their own circuits.

dApps compose the ACC in their own circuits, so the interface is part of the published artifact, versioned with the binding.

## Dependencies

**Blocked by:** E05.01 ACC artifact build and publication (ADR)

## Acceptance criteria

- A sample dApp circuit compiles against it.
