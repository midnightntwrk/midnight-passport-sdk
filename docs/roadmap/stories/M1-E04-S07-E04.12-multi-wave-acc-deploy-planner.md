# E04.12 Multi-wave ACC deploy planner

**Epic:** E04 · Account deployment · **Milestone:** 1 Foundation · **Step:** 7  
**Epic issue:** [#47](https://github.com/midnightntwrk/midnight-passport-sdk/issues/47)  
**Packages:** owner, contract  
**Readiness:** ready · **Sheet title:** Deploy in waves

## Description

The contract is too large for one transaction, so the deploy planner packs its circuits into several waves that fit the verifier budget.

Each wave registers a set of circuits within the verifier key budget of one transaction. The planner is resumable, so a failed wave is retried without redeploying the earlier ones.

- A failed wave resumes without redeploying earlier waves.
- No wave exceeds the verifier key budget.
