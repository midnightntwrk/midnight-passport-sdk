# E03.03 Seam interface definitions

**Epic:** E03 · Workspace, seams, and guardrails · **Milestone:** 1 Foundation · **Step:** 4  
**Epic issue:** [#46](https://github.com/midnightntwrk/midnight-passport-sdk/issues/46)  
**Packages:** core, owner  
**Readiness:** ready · **Sheet title:** Seam interfaces

## Description

Define the interfaces (seams) that adapters implement, such as the prover, storage, indexer, and key providers, so each can be swapped without touching the core.

The seams are typed interfaces in core (prover, broadcast, key provider, storage, platform, indexer, registry) and in owner (recovery, DID). Reads are observable and writes are imperative, so the shape already fits the later design.

## Acceptance criteria

- The prover, broadcast, key provider, storage, platform, and indexer seams compile in `core`; recovery and DID in `owner`.
- Each seam has a local-dev stub.
