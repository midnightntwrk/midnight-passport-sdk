# E06.01 Onboarding flow: passkey creation

**Epic:** E06 · Passport app: Onboarding · **Milestone:** 1 Foundation · **Step:** 7  
**Epic issue:** [#49](https://github.com/midnightntwrk/midnight-passport-sdk/issues/49)  
**Packages:** app  
**Readiness:** ready · **Sheet title:** Passkey onboarding

## Description

The sign-up flow: the user creates their account with face or fingerprint, with no seed phrase.

Built on owner. The user sees one passkey prompt, and the screen explains what face or fingerprint unlocks. No seed phrase is ever shown.
