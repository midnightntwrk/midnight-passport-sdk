# E02.02 UI component library and interaction patterns

**Epic:** E02 · Passport app: Brand and identity · **Milestone:** 1 Foundation · **Step:** 2

**Readiness:** ready · **Sheet title:** Design system

## Description

Reusable components and interaction patterns, plus the main UX decisions (navigation, ceremonies, error states) every screen follows.

Includes the passkey tap moments (grant issuance and the private-data handoff), the consent screens, and error states for refused sponsors or failed proofs.

## Dependencies

**Blocked by:** E02.01 Brand tokens: color, type, iconography  
**Unlocks:** E06.01 Onboarding flow: passkey creation; E12.01 Authorizer screens (browser and agent profiles); E20.02 Devices screen (owner key list)

## Acceptance criteria

- Components cover the onboarding screens.
- One pattern exists for every passkey tap and every consent.
- Error, loading, and progress states are defined.
