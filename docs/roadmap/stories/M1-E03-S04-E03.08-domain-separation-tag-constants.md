# E03.08 Domain-separation tag constants

**Epic:** E03 · Workspace, seams, and guardrails · **Milestone:** 1 Foundation · **Step:** 4  
**Epic issue:** [#46](https://github.com/midnightntwrk/midnight-passport-sdk/issues/46)  
**Packages:** protocol  
**Readiness:** ready · **Sheet title:** Domain-separation tags

## Description

One shared set of tag constants used by every signature and hash, so a signature for one purpose can't be reused for another.

The tags live in protocol and cover each signing arm's challenge digest, the grant request, the sign-in message, and the recovery messages.

## Dependencies

**Blocked by:** E03.02 Monorepo scaffold for mn-passport-* packages  
**Unlocks:** E04.02 KeyProvider across k256, p256, and JubJub; E09.01 GrantRequest: browser profile; E09.02 GrantRequest: agent profile; E09.03 Sign-in message (MIP §10); E14.01 Device enrollment request (QR or link payload); E16.01 MIP-0022 recovery message types

## Acceptance criteria

- One set of tag constants in `protocol` covers every signature and hash the SDK makes.
- A test fails if two purposes share a tag.
