## Description

Build and publish signed, reproducible package releases to npm.

Releases publish under @midnight-ntwrk/ with provenance. Every commit is GPG-signed with a DCO sign-off, and the loop never pushes or opens PRs on its own.

**Blocked by:** E03.01 Exact pins, 7-day cooldown, lockfile; E03.02 Monorepo scaffold for mn-passport-* packages  
**Unlocks:** no other story.

## Acceptance criteria

- A release is signed, has provenance, and is reproducible from a clean checkout.
- Packages publish under @midnight-ntwrk/.
