# E19.03 k256 wallet as an owner key

**Epic:** E19 · Devices and multi-device sync · **Milestone:** 6 Private data and sync · **Step:** 9  
**Epic issue:** [#57](https://github.com/midnightntwrk/midnight-passport-sdk/issues/57)  
**Packages:** core, owner  
**Readiness:** ready · **Sheet title:** Wallet as a device

## Description

Use a wallet the user already has as a signer for the account.

An existing wallet signs on a k256 envelope arm as an owner key. It is added like any other device, through the Passport app only (rule 11).

## Dependencies

**Blocked by:** E04.02 KeyProvider across p256, k256 and JubJub; E19.02 Owner key add and remove on the ACC  
**Unlocks:** no other story.

## Acceptance criteria

- An existing wallet is added as an owner key on a k256 arm.
