# E09.02 GrantRequest: agent profile

**Epic:** E09 · Scoped grants foundation · **Milestone:** 3 Control · **Step:** 5

## Description

The request an AI agent sends, with the actions, limits, and time window it wants.

The agent profile: a self-signature, a nonce, an expiry, and a label, delivered by QR code or link. Same GrantRequest type as the browser profile, with a different binding.
