# E11.03 connect: browser grant ceremony

**Epic:** E11 · Grant ceremony clients · **Milestone:** 3 Control · **Step:** 8  
**Epic issue:** [#54](https://github.com/midnightntwrk/midnight-passport-sdk/issues/54)  
**Packages:** connect  
**Readiness:** ready · **Sheet title:** Request a grant

## Description

The dApp asks for a grant, the user approves it in the Passport app, and the dApp gets its scoped key.

connect builds the browser GrantRequest, redirects to the Passport app, and receives the result. The grant key is made on the dApp origin.
