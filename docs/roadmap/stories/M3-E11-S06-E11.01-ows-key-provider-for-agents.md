# E11.01 OWS key provider for agents

**Epic:** E11 · Grant ceremony clients · **Milestone:** 3 Control · **Step:** 6  
**Epic issue:** [#54](https://github.com/midnightntwrk/midnight-passport-sdk/issues/54)  
**Packages:** agent  
**Readiness:** ready · **Sheet title:** Agent key in OWS

## Description

The agent's own key, held in OWS, never the user's key.

OWS is the key provider for the agent. The agent's key is its grant key. It never holds a device key or an owner key (rules 9 to 11).

**Blocked by:** E04.02 KeyProvider across k256, p256, and JubJub
